# 赞助 / 捐赠（国内平台）

本项目支持使用国内平台的“收款码/赞赏码”进行赞助

## 使用方式（维护者）

1. 准备二维码图片：
   - 微信：微信收款码 / 赞赏码截图或导出图片
   - 支付宝：支付宝收款码截图或导出图片
2. 将二维码文件放到本目录，并使用以下固定文件名（推荐）：
   - `wechat-pay.png`
   - `alipay.png`

仓库根目录的 README 会引用以下路径：

- `docs/sponsor/wechat-pay.svg`（占位图）
- `docs/sponsor/alipay.svg`（占位图）

你可以直接用同名的 PNG 替换它们（例如把 `wechat-pay.png` / `alipay.png` 改名为 `wechat-pay.svg` / `alipay.svg` 并不推荐），更推荐的做法是：

- 保持 README 引用不变：把占位 `*.svg` 文件替换成真实二维码图片，但仍然使用 `.svg` 扩展名

如果你希望保留真实文件扩展名（推荐），可以改 README 引用为：

- `docs/sponsor/wechat-pay.png`
- `docs/sponsor/alipay.png`

## 注意事项

- 建议二维码图像大小至少 600×600，避免缩放后无法识别
- 尽量避免把个人手机号、真实姓名等敏感信息直接暴露在二维码旁的文字里
- 如果你不希望在仓库中直接展示二维码，也可以只在 README 放一个国内平台的页面链接（例如爱发电/赞助页），不放二维码图片
